This is the top-level pnpm workspace root that orchestrates a multi-package TypeScript project. The workspace declares `packages/*` as member packages (pnpm-workspace.yaml), each representing a distinct concern: schema, registry, collectors, intelligence, publisher, and cli. A single tsconfig.json enforces strict TypeScript settings (ES2022 target, ESNext modules, bundler resolution, strict mode, isolatedModules, verbatimModuleSyntax) shared across all packages. Biome provides unified linting/formatting with single quotes, semicolons, trailing commas, and 100-line width. Scripts in package.json are workspace-wide shortcuts (`pnpm -r run ...`) that delegate to individual packages, while `generate` specifically targets `@basemodel/publisher` to regenerate datasets into `dist/`. Canonical Zod schemas live in `packages/schema`, canonical records in `data/registry/`, and generated outputs in `dist/`.
